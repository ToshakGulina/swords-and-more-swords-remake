# ⚔️ Swords and More Swords — Remake для Minecraft Bedrock 1.26.60+ (Android & Windows)

Полный ремейк и модернизация культового аддона **Swords and More Swords** от **Effect99** (на основе всех трёх оригинальных выпусков: **`V1.6`**, **`V2.8.8`** и **`V2.8.14`**), адаптированный под актуальный официальный **Minecraft Bedrock Edition `1.26.60` (`26.60`)** на **Android** и **Windows 10/11**.

Аддон предназначен для работы без экспериментальных переключателей и содержит русский и английский тексты и встроенный справочник. Эта сборка проверена статически и тестами с имитацией API, но **не проверена запуском в Minecraft**; импорт, интерфейс и игровые сценарии необходимо проверить на устройстве. Наборы параметров могут отключать достижения — перед установкой сделайте резервную копию мира.

---

## 📦 Архивы в репозитории — устаревшие, не финальный результат

Исходники и манифесты пакетов сейчас имеют версию `3.0.4`, но хранящийся в корне `.mcaddon` содержит версию `3.0.3` и не включает последние исправления. Отдельные `.mcpack` также нельзя считать актуальной сборкой без сверки. Не используйте эти архивы для проверки текущего кода; финальная сборка появится только после завершения игровых проверок. Ни одна версия ещё не подтверждена игровым тестированием.

## 📲 Пошаговая инструкция по установке

Инструкция ниже описывает порядок импорта для **будущей проверенной сборки** или отдельно предоставленной тестовой сборки. Архивы, перечисленные выше, устарели.

### 🪟 На ПК (Windows 10 / Windows 11)
1. Скачайте файл **`SwordsAndMoreSwords_Remake.mcaddon`**.
2. Дважды щёлкните по нему левой кнопкой мыши — **Minecraft Bedrock** автоматически запустится и покажет уведомление об успешном импорте обоих наборов (`Swords and More Swords (1.26+ Remake)` и `Swords and More Swords Resources (1.26+)`).
3. Нажмите **Играть -> Создать новый мир** (или нажмите карандаш рядом с существующим миром):
   - Откройте вкладку **Наборы параметров (Behavior Packs)** -> в разделе *Доступные* выберите **`Swords and More Swords (1.26+ Remake)`** -> нажмите **Активировать**.
   - Откройте вкладку **Наборы ресурсов (Resource Packs)** и убедитесь, что **`Swords and More Swords Resources (1.26+)`** также находится в списке **Активных** (обычно подключается автоматически по UUID-зависимости).
4. **Никакие экспериментальные функции включать НЕ нужно!** Создайте или запустите мир.

### 🤖 На телефон / планшет (Android)
1. Скачайте файл **`SwordsAndMoreSwords_Remake.mcaddon`** на устройство.
2. Откройте встроенный файловый менеджер (или бесплатный проводник **Cx Проводник / ZArchiver / Files by Google** — стандартное окно «Загрузки» в некоторых браузерах Android иногда переименовывает `.mcaddon` в `.zip`).
   - *Совет:* если браузер добавил в конце `.zip` (`SwordsAndMoreSwords_Remake.mcaddon.zip`), переименуйте файл, убрав `.zip`, чтобы он заканчивался ровно на **`.mcaddon`**.
3. Нажмите на файл **`SwordsAndMoreSwords_Remake.mcaddon`** и в списке **«Открыть с помощью»** выберите **Minecraft** -> *Только сейчас / Всегда*.
4. Дождитесь обоих всплывающих уведомлений об успешном импорте наверху экрана.
5. При создании или редактировании мира активируйте мод во вкладках **Наборы параметров** и **Наборы ресурсов**. Начните с выключенных экспериментальных переключателей и используйте копию мира.

## 📖 Как открыть справочник мода в игре (как в оригинале!)

Весь оригинальный иллюстрированный справочник мода со скриншотами крафтов, руд, боссов и характеристиками всех **38 мечей** полностью переведён на **русский** и **английский** языки и адаптирован под интерфейс `1.20.50`–`1.26.60`:
1. **Красная иконка меча в правом верхнем углу окна Инвентаря** (справа рядом с крестиком `X`, а также в окнах верстака, печи и наковальни) — открывает экран энциклопедии (`ui/encyclopedia_screen.json`) со всеми разделами мода!
2. **Кнопка справочника в меню Паузы** (куда разработчики Mojang в современных версиях перенесли бывший раздел «Как играть» из Настроек) — открывает тот же самый справочник мода (`ui/how_to_play_screen.json`).
3. Язык справочника (**Русский** или **English**) переключается автоматически в зависимости от выбранного языка интерфейса самого Minecraft.

## 🔍 Сверка версий оригинала (`1.6` vs `2.8.8` vs `2.8.14`) и точное число мечей

При создании ремейка были побайтово сверены все три оригинальных архива автора Effect99:
- **`V1.6` (`Swords V1.6.mcaddon`)**: ранняя классическая сборка на **26 мечей** (где у всех мечей были простые крафты на верстаке — например, *Sword of Time* из часов, *Ender Sword* из жемчуга, *Fire Sword* из огненного порошка, *Ice Sword* из синего льда).
- **`V2.8.8` (`Swords and More Swords 2.8.8.mcaddon`)**: эталонный полный релиз автора — расширен до **42 предметов** (**38 мечей** + 2 боевые палки + 2 материала), 7 боссов/мобов, 2 руд, генерации руд (включая Эндер-мир), торговли с Мастером-оружейником, Фонтана Желаний в пустынном колодце и 3D-превращений игрока (Оборотень, Хвост Русалки, Прозрачные ноги Призрака).
- **`V2.8.14` (`Swords and More Swords 2.8.14.mcaddon`, внутренний заголовок `V2.8.9.5`)**: экстренный хотфикс автора под сломавшийся в 1.20.80/1.21 *Holiday Creator Features*, в котором были случайно вырезаны блок `fake_ice` (ледяная клетка Ледяного меча), все `features`/`feature_rules` (генерация руд в мире!), `structures/quartz_diamond_ore.mcstructure` и `trading/` (торговля Изумрудным мечом у оружейника). **В нашем ремейке всё это полностью восстановлено из `2.8.8` и переведено на стабильные стандарты `1.26.60`!**

### Итоги последнего прохода аудита паритета

Что исправлено (доказано файлами `2.8.8`):

| Область | Было в ремейке | Стало как в `2.8.8` |
|---|---|---|
| Grass Witch | ванильный лут ведьмы + 20 % меч по условию | компонент `loot: {}`, меч — скриптовые 20 % при любой смерти |
| Spider mount | неполная группа | точный набор family/hp/jump/loot/seat, `attack.damage 3` |
| Динамический свет | один блок над головой; `lightblock2` яркость 11 | куб 3×3×3, у Ultra Instinct и Wither — слой `~ ~2 ~`; яркость 15 и 7 (`0.5` от `0-1` в старом API) |
| `quartz_diamond_block` / `ore` | свет 4 и 3 | свет 0 (в `2.8.8` не светились) |
| How to Play | выдуманная страница Cursed Pumpkin Sword | 40 разделов, как в оригинале |
| Fire Sword | пустой `hurt_on_condition` | убран; иммунитет к огню даёт `damage_sensor` |
| Трейд Изумрудного меча | уровень 250, 30 опыта торговцу | уровень 310, `trader_exp 0`, `max_uses 2` |

Намеренные отличия от `2.8.8` (задокументированы в коде):

- **Slime King** — таблица `loot_tables/entities/slime_king.json` (4 % + 2 % за уровень «Разграбления») в оригинале лежала в паке, но ни одна сущность на неё не ссылалась, поэтому меч из короля не выпадал. Таблица подключена — баг оригинала исправлен.
- **Spawn rules** (`alpha_wolf`, `ghost`, `living_flame`, `slime_king`) — `minecraft:grass`/`minecraft:stone` заменены на современные блоки, добавлены `spawn_event`, которые в оригинале существуют, но никогда не вызывались (молчаливый Ghost, пассивный Living Flame).
- **Trading** — остальные девять трейдов оружейника оставлены ванильными: в `2.8.8` лежала устаревшая копия таблицы `1.13`, не связанная с мечами.

### Почему в тексте `2.8.8` упоминалось «39 мечей», хотя в файлах их 38?
В папке `Swords_B/items/` оригинальных версий `2.8.8` и `2.8.14` ровно **42 файла предметов**:
- **38 уникальных мечей** в категории мечей: 37 описанных в справочнике (считая отдельно сухой `sponge_sword` и мокрый `wet_sponge_sword`) + **38-й секретный недокументированный меч** `pumpkin_sword.json` -> **`effect:cursed_pumpkin_sword`** (*Проклятый тыквенный меч*), который выпадал с шансом `0.5%` при ломании тыкв через скрипт!
- **2 особые боевые палки**: `effect:bedrock_stick` (6 урона, неразрушимая) и `effect:quartz_diamond_stick` (24 урона, прочность 20).
- **2 материала**: `effect:silver_ingot` и `effect:quartz_diamond`.
- Строка `"39 swords"` в оригинальном `en_US.lang` появилась из-за подсчёта заголовков `.header.title=` в файле локализации: их там ровно **39** (4 информационные вкладки + 35 вкладок мечей). В ремейке присутствуют **абсолютно все 38 мечей** (плюс обе боевые палки и оба материала — ровно все **42 предмета** оригинала без лишнего мусора в инвентаре).

## 🛠️ Сборка и валидация из исходников (для разработчиков)

Исходный код скриптов написан на TypeScript под `@minecraft/server@2.6.0`. Для воспроизводимой сборки нужны Node.js, npm, `zip`, оригинал 2.8.8 и внешние справочные файлы; оригинал и справочные файлы в репозиторий не включены. Пути можно задать переменными окружения, примеры ниже — для bash.

```bash
npm ci

# Вне репозитория: точные ревизии справочных файлов, использованные при проверке.
git clone https://github.com/Mojang/bedrock-samples.git /path/to/bedrock-samples
git -C /path/to/bedrock-samples checkout 4d30ae63750467771b6eccda105f732c6cb77ff7
git clone https://github.com/Blockception/Minecraft-bedrock-json-schemas.git /path/to/schemas
git -C /path/to/schemas checkout c2859d0d99d3cfad7e0f08656af7c0bae045f956

# В каталоге оригинала должны находиться Swords_B и Swords_R версии 2.8.8.
export SAMS_ORIGINAL=/path/to/unpacked-original-2.8.8
export SAMS_SAMPLES=/path/to/bedrock-samples
export SAMS_SCHEMAS=/path/to/schemas

npm run build:data  # перегенерировать JSON, сущности, локализацию и восстановленные таблицы добычи
npm run compile     # скомпилировать скрипты
npm run validate    # статическая проверка по схемам и ссылкам
npm test            # структурные и мок-тесты, включая сравнение с оригиналом
npm run package     # собрать .mcaddon и отдельные .mcpack (нужна утилита zip)
```

Без переменных используются прежние пути `/tmp/mcaddons/2.8.8`, `/tmp/refs/bedrock-samples` и `/tmp/refs/schemas`. Статические и мок-тесты не заменяют запуск в Bedrock: особенно важно проверить интерфейс, генерацию мира, освещение и игровые события на Android и Windows.

План обязательной игровой проверки и условия приёмки: [TESTING.md](TESTING.md).

Результаты построчной сверки с оригиналом 2.8.8 — что исправлено, что проверено и оставлено осознанно: [PARITY_2.8.8.md](PARITY_2.8.8.md).
